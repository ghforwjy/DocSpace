## 🏗️ API 服务架构

DocSpace API 由以下服务提供：

| 服务模块 | 负责功能 | 主要 Controller 位置 |
|---------|---------|-------------------|
| **认证服务** | 登录、验证、注销 | `server/web/ASC.Web.Api/Api/AuthenticationController.cs` |
| **用户服务** | 用户管理、资料、群组 | `server/products/ASC.People/Server/Api/` |
| **文件服务** | 文件、文件夹、版本 | `server/products/ASC.Files/Server/Api/` |
| **房间服务** | 房间、协作管理 | `server/products/ASC.Files/Server/Api/VirtualRoomsController.cs` |
| **安全服务** | 权限、分享 | `server/products/ASC.Files/Server/Api/SecurityController.cs` |

## 📋 API 基础信息

### 基础路径
所有 API 调用的基础路径为：
```
{baseUrl}/api/2.0/
```

### 请求格式
- **Content-Type**: `application/json`
- **Accept**: `application/json`
- **请求方式**: GET、POST、PUT、DELETE

### 认证方式
- **Cookie 认证**: 标准的会话 Cookie
- **API Key**: 适用于服务器端集成
- **OAuth 2.0**: 适用于第三方应用

### 速率限制
- 每分钟最多 1500 个认证请求
- 同时最多 50 个 GET 请求
- 同时最多 15 个非 GET 请求

### 常用状态码
| 状态码 | 说明 |
|-------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未认证或认证失败 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁 |
