## 一、系统架构概览

### 1.1 技术栈

| 层级 | 技术 |
|-----|------|
| 框架 | React 18 + TypeScript |
| 状态管理 | MobX |
| 样式 | Styled-Components + SCSS |
| 路由 | React Router v6 |
| 国际化 | i18next |
| 构建 | Webpack 5 |
| 包管理 | pnpm (monorepo) |

### 1.2 项目结构

```
packages/
├── client/          # 主客户端应用
├── shared/          # 共享组件、API、枚举
├── doceditor/       # 文档编辑器
├── login/           # 登录模块
├── management/      # 管理后台
└── sdk/             # SDK工具
```

### 1.3 核心概念

- **Room（房间）**：文档协作的基本空间单元，包含独立的权限体系和成员管理
- **Folder（文件夹）**：传统的层级目录结构
- **File（文件）**：文档、表格、演示文稿等
- **Link（分享链接）**：外部访问的入口
- **Member（成员）**：房间或文档的协作用户

## 三、房间功能分析

### 3.1 房间类型（RoomsType）

DocSpace 定义了 **6种房间类型**：

| 枚举值 | 类型名称 | 中文名称 | 用途描述 |
|-------|---------|---------|---------|
| `FormRoom = 1` | Form Filling Room | 表单填写房间 | 用于分发和收集表单填写，适合问卷调查、数据收集场景 |
| `EditingRoom = 2` | Collaboration Room | 协作房间 | 多人实时协作编辑文档，支持共同编辑、评论、聊天 |
| `CustomRoom = 5` | Custom Room | 自定义房间 | 灵活配置权限和功能的通用房间 |
| `PublicRoom = 6` | Public Room | 公共房间 | 通过公开链接访问，无需登录即可查看 |
| `VirtualDataRoom = 8` | Virtual Data Room | 虚拟数据室 | 高安全性文档共享，支持水印、访问审计 |
| `AIRoom = 9` | AI Room | AI房间 | AI辅助协作空间，集成AI助手功能 |

> 注：代码中保留了 `ReviewRoom(3)` 和 `ReadOnlyRoom(4)` 的注释占位，当前版本未启用。

### 3.2 创建房间对话框（CreateRoomDialog）

**触发方式**：
- 主操作按钮 → "创建" → "创建房间"
- 导航菜单 → 房间列表页 → 创建按钮

#### 3.2.1 第一步：选择房间类型（RoomTypeList）

**界面元素**：

| 元素 | 类型 | 说明 |
|-----|------|------|
| 协作房间卡片 | 可点击卡片 | 显示房间图标、标题、描述 |
| 虚拟数据室卡片 | 可点击卡片 | 显示安全等级标识 |
| 自定义房间卡片 | 可点击卡片 | 显示配置选项提示 |
| 公共房间卡片 | 可点击卡片 | 显示公开访问标识 |
| 表单填写房间卡片 | 可点击卡片 | 显示表单图标 |
| AI房间卡片 | 可点击卡片 | 显示AI标识 |
| 从模板创建卡片 | 可点击卡片 | 跳转到模板选择器 |
| 返回按钮 | 图标按钮 | 返回上一步（如适用） |
| 关闭按钮 | 图标按钮（X） | 关闭对话框 |

**房间类型卡片内容**：
- 房间类型图标
- 房间类型标题（如 "协作房间"）
- 房间类型描述（如 "与团队成员实时协作编辑文档"）
- 悬停效果

#### 3.2.2 第二步：设置房间参数（SetRoomParams）

**表单字段**：

| 字段 | 控件类型 | 必填 | 说明 |
|-----|---------|------|------|
| 房间图标 | 图标选择器 | 否 | 上传图片或选择预设图标 |
| 房间名称 | 文本输入框 | 是 | 房间显示名称，有验证规则 |
| 房间类型 | 下拉选择器 | 是 | 可切换已选的房间类型 |
| 标签 | 标签输入框 | 否 | 添加分类标签，支持多标签 |
| 存储位置 | 选择器 | 否 | 本地或第三方存储（如Google Drive） |
| 房间配额 | 只读显示 | - | 显示存储空间限制 |
| 有效期设置 | 日期选择器 | 否 | 设置房间自动归档时间 |

**按钮**：

| 按钮 | 类型 | 说明 |
|-----|------|------|
| 创建 | 主按钮（Primary） | 提交创建，名称非空时可用 |
| 取消 | 次要按钮 | 关闭对话框，放弃创建 |
| 返回 | 图标按钮 | 返回房间类型选择 |

#### 3.2.3 从模板创建流程

**模板选择器（RoomSelector）**：
- 搜索框（按名称搜索模板）
- 模板列表（显示模板名称、类型、图标）
- 空状态提示（无模板时）
- 返回按钮
- 选择确认

### 3.3 编辑房间对话框（EditRoomDialog）

**与创建对话框的区别**：
- 预填充现有房间数据
- 增加 **更改所有者**（ChangeRoomOwner）下拉选择器
- 增加 **删除房间** 选项
- 增加 **归档房间** 选项

### 3.4 房间操作菜单

#### 3.4.1 房间卡片上下文菜单

**右键点击房间卡片时显示**：

| 菜单项 | 图标 | 功能 |
|-------|------|------|
| 打开 | 文件夹图标 | 进入房间 |
| 编辑房间 | 编辑图标 | 打开编辑对话框 |
| 复制链接 | 链接图标 | 复制房间访问链接 |
| 邀请用户 | 用户+图标 | 打开邀请对话框 |
| 归档 | 归档图标 | 移动到归档区 |
| 删除 | 删除图标 | 删除房间（需确认） |
| 离开房间 | 退出图标 | 退出当前房间 |
| 更换所有者 | 转移图标 | 转移房间所有权 |

#### 3.4.2 房间内文件操作菜单

与常规文件操作菜单相同，见 [四、文档管理功能分析](#四文档管理功能分析)。

### 3.5 房间信息面板

**详情标签页显示**：
- 房间图标和名称
- 房间类型标签
- 创建者信息
- 创建时间
- 成员数量
- 文件数量
- 存储使用量
- 标签列表

## 六、信息面板（InfoPanel）

- 快捷键（如适用）

### 6.1 详情标签（Details）

| 字段 | 说明 |
|-----|------|

| 名称 | 显示名称（可编辑） |

| 修改时间 | 最后修改日期时间 |

### 6.2 分享标签（Share）

- 成员列表（同分享对话框）
