## 四、Docker 镜像定制方式

由于 DocSpace 和 DocumentServer 均以 Docker 镜像运行，定制方式分为以下三类：

### 4.1 环境变量覆盖（无需重建镜像）

DocumentServer 支持在 `docker-compose` 中通过环境变量覆盖默认配置：

```yaml
environment:
  - SUPPORT_EMAIL=support@example.com
  - SUPPORT_URL=https://support.example.com
  - SALES_EMAIL=sales@example.com
  - PUBLISHER_URL=https://www.example.com
  - HELP_URL=https://help.example.com
```

| 环境变量 | 覆盖内容 |
|---------|---------|
| `SUPPORT_EMAIL` | 支持邮箱 |
| `SUPPORT_URL` | 支持链接 |
| `SALES_EMAIL` | 销售邮箱 |
| `PUBLISHER_URL` | 发布商链接 |
| `HELP_URL` | 帮助中心链接 |

### 4.2 文件挂载覆盖（无需重建镜像）

DocumentServer 的 branding 资源可以通过 **Docker volume 挂载** 覆盖，容器会优先使用挂载的自定义文件：

```yaml
volumes:
  - ./custom-branding/info:/var/www/onlyoffice/Data_center/public/branding/info
  - ./custom-branding/welcome:/var/www/onlyoffice/Data_center/public/branding/welcome
```

可挂载覆盖的内容：
- `branding/info/` → info 页的 logo、favicon、HTML
- `branding/welcome/` → welcome 页的 logo、favicon、HTML

### 4.3 需要重建镜像的情况

以下内容的定制**必须重新构建** DocumentServer 镜像：

| 定制内容 | 原因 | 源码位置 |
|---------|------|---------|
| **帮助文档链接** | 在 build 阶段通过 `Gruntfile.js` 注入，写死在 HTML 中 | `web-apps/apps/*/main/resources/help/` |
| **Editor favicon** | 构建时产物，无法通过运行时覆盖 | `web-apps/apps/*/main/resources/img/favicon.ico` |

### 4.4 定制建议总结

| 定制目标 | 推荐方式 |
|---------|---------|
| Logo 图片、品牌页面 UI | **文件挂载** |
| 外部链接（支持/销售/Help） | **环境变量** |
| 帮助文档中的链接 | **重建镜像** |
| Editor favicon | **重建镜像** |

## 五、源码级定制流程

### 5.1 Logo 定制流程

1. **前端 Logo**: 替换 `DocSpace/client/public/images/logo/` 下的 SVG/ICO 文件
2. **DocumentServer Logo**: 替换 `DocSpace/DocumentServer/server/branding/` 下的图片
3. **服务器端 Logo**: 替换 `DocSpace/server/web/ASC.Web.Core/PublicResources/` 下的 PNG

### 5.2 链接定制流程

1. **DocumentServer 链接**: 修改 `DocSpace/DocumentServer/web-apps/build/Gruntfile.js` 中的默认值
2. **品牌页面**: 修改 `DocSpace/DocumentServer/server/branding/` 下的 HTML 文件
3. **帮助文档**: 需要批量替换 `DocSpace/DocumentServer/web-apps/apps/*/main/resources/help/` 下的链接

### 5.3 环境变量覆盖

以下配置可通过环境变量覆盖：

| 环境变量 | 说明 |
|---------|------|
| `SUPPORT_EMAIL` | 支持邮箱 |
| `SUPPORT_URL` | 支持链接 |
| `SALES_EMAIL` | 销售邮箱 |
| `PUBLISHER_URL` | 发布商链接 |
| `API_URL_EDITING_CALLBACK` | API 回调地址 |
| `HELP_URL` | 帮助中心链接 |
