# 邮箱服务配置流程

## 概述

DocSpace 支持配置自定义 SMTP 服务器用于发送邮件通知。本文档记录 SMTP 设置的配置流程、关键代码路径和问题排查方法。

---

## SMTP 设置页面

**URL**: `/portal-settings/integration/smtp-settings`

### 页面元素

| 元素 | 说明 | 必填 |
|------|------|------|
| 主机 | SMTP 服务器地址 | 是 |
| 端口 | SMTP 端口号 | 是 |
| 身份验证 | 是否启用认证 | - |
| 主机登录 | SMTP 认证用户名 | 启用认证时必填 |
| 主机密码 | SMTP 认证密码 | 启用认证时必填 |
| 通过 NTLM 授权 | 是否使用 NTLM 认证 | - |
| 发件人显示名称 | 邮件显示的发件人名称 | - |
| 发件人电邮地址 | 邮件显示的发件人地址 | 是 |
| 启用SSL | 是否启用 SSL/TLS 加密 | - |

### 端口说明

| 端口 | SSL类型 | 说明 | 兼容性 |
|------|---------|------|--------|
| 25 | 无 | 标准 SMTP 端口 | 云服务商通常封禁 |
| 465 | SSL/SMTPS | SMTPS 加密连接 | 常用 |
| 587 | STARTTLS | SMTP + STARTTLS 升级 | 部分邮箱不支持 |

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/2.0/smtpsettings/smtp` | 获取当前 SMTP 配置 |
| POST | `/api/2.0/smtpsettings/smtp` | 保存 SMTP 配置 |
| GET | `/api/2.0/smtpsettings/smtp/test` | 触发发送测试邮件 |
| GET | `/api/2.0/smtpsettings/smtp/test/status` | 获取测试邮件发送状态 |

### 测试邮件流程

```
1. 前端调用 GET /api/2.0/smtpsettings/smtp/test
2. 后端启动 SmtpJob 后台任务，返回 operationId
3. 前端轮询 GET /api/2.0/smtpsettings/smtp/test/status
4. 状态返回: { percentage, currentOperation, completed, error }
5. completed=true 时表示任务完成
```

## 邮件发送实现 (SmtpJob.cs)

### 连接配置

```csharp
await client.ConnectAsync(
    _smtpSettings.Host,
    _smtpSettings.Port.GetValueOrDefault(SmtpSettings.DefaultSmtpPort),
    _smtpSettings.EnableSSL ? SecureSocketOptions.Auto : SecureSocketOptions.None
);
```

### 认证配置

```csharp
if (_smtpSettings.EnableAuth)
{
    if (_smtpSettings.UseNtlm)
    {
        var saslMechanism = new SaslMechanismNtlm(
            _smtpSettings.CredentialsUserName,
            _smtpSettings.CredentialsUserPassword
        );
        await client.AuthenticateAsync(saslMechanism);
    }
    else
    {
        await client.AuthenticateAsync(
            _smtpSettings.CredentialsUserName,
            _smtpSettings.CredentialsUserPassword
        );
    }
}
```

### 错误处理

| 异常类型 | 说明 |
|----------|------|
| `AuthorizingException` | 访问被拒绝 |
| `SocketException` | 网络连接错误 |
| `AuthenticationException` | 认证失败 |
| `TaskCanceledException` | 任务取消 |

## 常见邮箱服务配置

### 163 邮箱

| 配置项 | 值 |
|--------|-----|
| 主机 | smtp.163.com |
| 端口（SSL） | 465 |
| 端口（STARTTLS） | 587（部分不支持） |
| 启用SSL | 是 |
| 认证用户名 | 完整邮箱地址 |
| 认证密码 | **SMTP 授权码**（非登录密码） |

**注意**: 163 邮箱必须使用授权码进行 SMTP 认证，授权码需要在 163 邮箱设置中单独生成。

### QQ 邮箱

| 配置项 | 值 |
|--------|-----|
| 主机 | smtp.qq.com |
| 端口 | 465 |
| 启用SSL | 是 |
| 认证密码 | **SMTP 授权码**（非登录密码） |

## 问题排查

### 问题：测试邮件发送无响应

**可能原因**:
1. 25 端口被云服务商封禁
2. SMTP 服务器无响应
3. 网络防火墙阻止

**排查方法**:
```bash
# 测试端口连通性
nc -zv smtp.example.com 25
nc -zv smtp.example.com 465
nc -zv smtp.example.com 587

# 测试 SSL 连接
openssl s_client -connect smtp.163.com:465 -servername smtp.163.com
```

### 问题：535 authentication failed

**可能原因**:
1. 用户名或密码错误
2. 使用了登录密码而非授权码（163/QQ 邮箱）
3. 邮箱未开启 SMTP 服务

**排查方法**:
```bash
# 手动测试 SMTP 认证
{ echo "EHLO test"; echo "AUTH LOGIN"; echo "base64用户名"; echo "base64密码"; echo "QUIT"; } \
  | openssl s_client -connect smtp.163.com:465 -servername smtp.163.com
```

### 问题：SMTP server has unexpectedly disconnected

**可能原因**:
1. SSL/TLS 配置错误
2. 服务器不支持配置的 SSL 模式
3. 端口与 SSL 模式不匹配

**排查方法**:
- 确认启用SSL时使用 465 端口（SMTPS）
- 确认禁用SSL时使用 25 端口或使用 STARTTLS 的 587 端口

## 配置文件存储

SMTP 配置存储在数据库的 `mail.settings` 表中。

### 配置字段

| 字段 | 说明 |
|------|------|
| Host | SMTP 服务器地址 |
| Port | 端口号 |
| EnableSSL | 是否启用 SSL |
| EnableAuth | 是否启用认证 |
| UseNtlm | 是否使用 NTLM |
| CredentialsUserName | 认证用户名 |
| SenderDisplayName | 发件人显示名称 |
| SenderAddress | 发件人地址 |

**注意**: 密码字段在返回给前端时会被清空。
